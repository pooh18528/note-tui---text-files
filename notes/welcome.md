# ยินดีต้อนรับสู่ note-tui 📝

note-tui คือโปรแกรมจดโน้ตแบบ Terminal UI (TUI) ที่เน้นความเรียบง่าย รวดเร็ว และบันทึกโน้ตทุกตัวเป็น **Text File (.md / .txt)** จริงบนเครื่องของคุณ

## ✨ จุดเด่นของ note-tui
- 📁 **ไฟล์ข้อความธรรมดา**: แก้ไข ย้าย หรือซิงค์ผ่าน Git/Cloud ได้ทันที
- 🎨 **สวยงาม Modern TUI**: ออกแบบด้วย Lip Gloss และ Charm Bubble Tea
- ⚡ **ค้นหาเร็วทันใจ**: กด `/` เพื่อค้นหาข้อความหรือชื่อโน้ตแบบเรียลไทม์
- ⌨️ **Keyboard Driven**: รองรับการใช้งานผ่านแป้นพิมพ์เต็มรูปแบบ

---
*เริ่มเขียนโน้ตใหม่โดยกด `n` ได้เลย!*
