# Keybindings Quick Reference ⌨️

Here is a quick list of keyboard shortcuts supported in **note-tui**:

## 📋 Navigation Mode (Notes List)
- `j` / `Down` : Move cursor down
- `k` / `Up` : Move cursor up
- `Enter` / `v` : View selected note content
- `n` : Create a new note
- `e` : Edit selected note
- `d` : Delete selected note (with confirmation prompt)
- `/` : Search notes in real-time
- `r` : Refresh notes list from disk
- `q` : Quit note-tui

## ✏️ Edit Mode
- `Ctrl+S` : Save changes to text file
- `Esc` : Cancel editing / back to list

## 🔍 Search Mode
- `Type query` : Filter notes instantly by title or content
- `Esc` : Clear search filter
